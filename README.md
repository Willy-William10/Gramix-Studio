# 🎨 Gramix Gradient Mixer

**Gramix Gradient Mixer** is a modern, interactive gradient creation tool designed to make creating, experimenting with, and saving gradients simple and enjoyable.

Whether you're designing a website, UI, artwork, wallpaper, or just experimenting with colors, Gramix gives you a visual workspace for exploring gradients.

## 🌈 Gradient Mixer

Create gradients visually and customize them exactly how you want.

* Add and remove color stops
* Change the color of each stop
* Move stops to control their positions
* Create gradients with multiple colors
* Experiment with different color combinations
* See changes instantly in the live preview
* Select individual stops for precise editing
* Easily experiment with different gradient compositions

The editor is designed to make gradient creation feel visual and interactive rather than requiring you to manually write CSS.

## 🎨 Color Harmony Lab

Explore color relationships and discover combinations that work well together.

The Harmony Lab helps you experiment with different color harmony approaches and use the resulting colors as inspiration for your gradients.

It makes exploring color combinations easier, even if you don't have much experience with color theory.

## 🖌️ Palette Collection

Explore a large collection of color palettes for inspiration.

You can:

* Browse palettes
* Filter palettes
* Preview palette colors
* Save palettes you like
* Use saved palettes as inspiration for new gradients

Instead of starting with a blank canvas every time, you can quickly find a palette and build from it.

## 💾 Save Gradients

Found a gradient you like?

Save it.

Saved gradients can be accessed later through **History**, allowing you to keep the gradients you've created without having to recreate them.

Gramix is designed to make saving and returning to your creations quick and simple.

## 🕘 History

The History section keeps track of your saved gradients and palettes.

It gives you a convenient place to return to previous creations and continue experimenting with them.

Your saved work is designed to remain available between sessions using local browser storage.

## 🎯 Compact Output

Gramix provides a compact output area for your generated gradient.

This makes it easy to take the gradient you've created and use it elsewhere, especially when working on websites and other digital projects.

## 🌓 Light & Dark Mode

Gramix supports both light and dark visual modes.

The interface adapts its controls and visual elements to match the selected theme, keeping important controls and selections visible in both modes.

## ✨ Interactive Interface

Gramix isn't just a static gradient generator.

The interface includes interactive elements, animations, visual feedback, and responsive controls designed to make experimenting with colors feel smooth and engaging.

Selected gradient stops, controls, previews, palettes, and other elements provide visual feedback as you work.

## 📖 Interactive Tutorial

Gramix includes an interactive tutorial that explains the main tools and features.

It uses multiple slides, animations, and visual demonstrations to help users understand how the mixer works and how to use its different features.

## 💻 Local-First Experience

Gramix is designed to work without requiring an account or login.

Your saved gradients and related data are stored locally in your browser, allowing you to continue working with your creations without needing a cloud account.

This also means your saved data is tied to the browser/device where it was created.

## 🎨 Built for Experimentation

Gramix is ultimately a creative playground for gradients.

You can start with a palette, experiment with color harmonies, adjust individual stops, save different versions, and return to previous creations whenever you want.

**Create a gradient. Experiment with it. Save it. Make something better.**
